# OmniMod

Downloads for OmniMod, a Windows app for streamers and gamers: soundboard, automations, stream overlays, drawable crosshairs and in-game stats.

## Install

1. Open [Releases](https://github.com/Reetusin/omnimod-releases/releases/latest) and download `OmniMod-Setup-<version>.exe`.
2. Run it. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. The app isn't digitally signed yet.
3. It installs for your Windows user, with no admin password needed.

Installed copies update themselves. When a new version is ready, OmniMod shows what's new and offers to restart.

This repository only holds the installers. The app's source code isn't here.
